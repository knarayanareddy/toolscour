# ToolScour static review

## Scope and verdict

**Repository:** [knarayanareddy/toolscour](https://github.com/knarayanareddy/toolscour), pinned `ce18eb1dd7de90695e6a4b42888f88eadd592500` on `main`. **Stage:** implementation/prototype: a React catalog and Python data pipeline exist, but a static sample cannot establish production readiness. The strongest findings concern fabricated positive license defaults, degraded harvests that can still deploy, and keyboard access. Runtime, installation, build, tests, deployment, accessibility tooling, and network probes of the application were **not run**, by instruction.

Confidence is high in the quoted code paths, conditional where behavior depends on actual records, APIs, browser rendering, or hosting configuration. This is a targeted sample, not a full repository audit. The tree was not truncated; that inventory is not equivalent to reading every file.

The [README](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/README.md#L38-L55) describes the Python harvester, sharder and stack generator alongside a separate `web/` application. The [harvester](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/harvest_ai_tools.py#L120-L136) calls GitHub GraphQL with a bearer token; [Hugging Face](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/harvest_ai_tools.py#L194-L225) supplies optional model data. The graph and stack modules were not inspected internally. No backend or authentication service is evidenced by these sampled paths; do not infer their absence elsewhere.

## Findings ledger

### F1 — Missing intelligence and generated license advice can mislead (high, confirmed static)

These are distinct conditional paths, not a claim that every missing source license is treated as permissive. For enriched input with no source license, [taxonomy_ai.py:813–828](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/taxonomy_ai.py#L813-L828) passes `Unknown` to the classifier; its [default:534–538](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/taxonomy_ai.py#L534-L538) reports `Custom Terms` and `Review`, not low risk. Separately, missing intelligence triggers positive object-level fallbacks in [shard_builder.py:144–147](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/shard_builder.py#L144-L147) and [App.jsx:208–213](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/src/App.jsx#L208-L213). A truthy but incomplete object can also trigger field-level `Permissive Open Source`/`Low` defaults at [App.jsx:1135–1142](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/src/App.jsx#L1135-L1142).

A further example is an enriched, non-landmark GitHub record with no supplied `beginner_intel` and license `CC-BY-NC-4.0`. The [classifier:495–505](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/taxonomy_ai.py#L495-L505) marks it non-commercial, while the [generator:769–774](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/taxonomy_ai.py#L769-L774) can append `Its {lic_display} license makes it safe to build products on.` This is not universal: Unknown/NOASSERTION and GPL-family branches are treated differently, supplied intelligence avoids generation, and a [later landmark override:870–879](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/taxonomy_ai.py#L870-L879) may replace fields. The [generated record:831–862](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/taxonomy_ai.py#L831-L862) reaches a tier-two deep record through [shard_builder.py:137–143](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/shard_builder.py#L137-L143), then the [display:1083–1089](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/src/App.jsx#L1083-L1089). Affected record counts and actual legal permissions were not established. Remove unsupported assurances at the generator as well as positive missing-data fallbacks; retain explicit unknown/review states and source-bound guidance.

### F2 — Harvest errors do not prevent a stale or partial deploy (high, confirmed static)

[harvest_ai_tools.py:167–191](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/harvest_ai_tools.py#L167-L191) prints GraphQL errors or exceptions and breaks the current query; [lines 250–263](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/harvest_ai_tools.py#L250-L263) merge prior records, while [lines 280–298](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/harvest_ai_tools.py#L280-L298) still write and print `Harvest complete`. The [deployment workflow](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/.github/workflows/deploy.yml#L32-L38) follows with packing. A provider failure can therefore produce a successful-looking release with stale or incomplete data; actual incident frequency is unknown. Define required-source health and freshness thresholds, report degradation, and gate publication without destroying the last known-good artifact.

### F3 — Catalog cards are not keyboard controls (medium, confirmed static)

[App.jsx:805–812](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/src/App.jsx#L805-L812) attaches `onClick` to a plain `div`, with no keyboard handler or focusability in the opening element. Keyboard-only users cannot activate that card using normal Tab/Enter navigation. The [modal](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/src/App.jsx#L933-L936) is also rendered as ordinary divs; focus handling and dialog semantics require browser verification. Use native interactive controls and a properly labelled dialog with focus return.

### F4 — Tier-one link reconstruction ignores source (medium, confirmed static)

The [HF harvester](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/harvest_ai_tools.py#L213-L225) sets `source: "huggingface"` and a Hugging Face URL; [packed rows](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/shard_builder.py#L98-L114) carry neither. [App.jsx:140–143](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/src/App.jsx#L140-L143) constructs a GitHub URL for every row. The [deep record](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/pipeline/shard_builder.py#L148-L151) can override it after a successful shard fetch; before that or after failure, a Hub entry can show/copy a wrong source URL. Preserve source and canonical URL end-to-end, and test slow and failed shard responses.

### F5 — Release gate does not run behavioral tests (medium, confirmed static)

The [web manifest](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/package.json#L6-L10) defines `dev`, `build`, and `preview`, but no test script; the [workflow](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/.github/workflows/deploy.yml#L47-L67) runs `npm ci` and `npm run build` before deploying, not a test command. This does not prove no tests exist elsewhere. The recorded [successful Pages run](https://github.com/knarayanareddy/toolscour/actions/runs/41664024784) is historical CI for this same pinned SHA, not a fresh run or evidence that the above behaviors work.

## Five-discipline assessment

- **Correctness/code:** F1–F4 are code-path observations, not proof of affected corpus counts. Search latency and 60 FPS claims in the [README](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/README.md#L3-L5) are unmeasured.
- **Automation/testing:** F5 distinguishes the visible release path from the uninspected rest of the tree. No tests were executed.
- **DevOps/operations:** the workflow [schedules daily](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/.github/workflows/deploy.yml#L3-L9), while the README [also says Monday](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/README.md#L95-L95). Treat the workflow as the observed configuration; clarify intended cadence and verify actual run history. Restore and release controls are unknown.
- **OWASP/security:** token use and permissions are visible (F6); no actual credentials were inspected. Authentication/authorization for a backend is not evidenced in sampled paths, not certified absent. External metadata, URLs and copyable commands cross trust boundaries; [rendered quickstarts](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/src/App.jsx#L1224-L1235) and the [footer source link](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/src/App.jsx#L1291-L1298) need URL scheme, injection and provenance testing. No exploit is established. Lockfile integrity, advisories, secret leakage and data retention were not audited; public catalog data is intended for public hosting, but other data is unverified.
- **UI/UX/accessibility:** F3; [fetch failure](https://github.com/knarayanareddy/toolscour/blob/ce18eb1dd7de90695e6a4b42888f88eadd592500/web/src/App.jsx#L159-L162) only logs and stops loading, making a failure potentially resemble an empty catalog. Screen-reader behavior, mobile layout and contrast need actual testing.

## Production blockers and owner questions

Agree the minimum successful harvest, freshness SLO, behavior for optional Hugging Face failures, and who approves exceptions (F2). Confirm Pages environment, branch restrictions, release approvers, GitHub token scope and action pin maintenance; whether a previous artifact can be restored has not been verified. Decide whether dev-server LAN access is required. No hardware or signing requirement is evidenced; owner must confirm whether either is relevant.
